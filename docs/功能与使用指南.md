# Hyper Bot 功能与使用指南

适用版本为 **0.1.0-dev.61**。一个人要完成一项任务，可以直接开 Bot 对话。要让几个 Bot 接着处理同一批文件，就建一个群组。两种方式都有右侧预览，群组还会把成果写到你选择的本机文件夹。

## 首次启动

Windows 和 macOS 按 [Agent 部署说明](Agent-deployment.md)安装。在仓库根目录执行以下命令可构建并启动浏览器入口。Windows 也可以双击 `Hyper Bot.cmd` 打开桌面端。

```sh
npm ci
npm run setup:teaching
npm run build
npm start
```

在浏览器打开启动命令打印的本机地址。Windows PowerShell 可使用 `npm.cmd`。

按你要做的事配置依赖。打开左下角 **⋯ → 维护中心 → 本机依赖**，或点卡片上的 **检查依赖**。模型凭据可通过启动环境中的 `DEEPSEEK_API_KEY` 提供，Windows 桌面也可在本机应用中录入。修改选项后重新检测。

| 要做的事 | 需要准备 |
|---|---|
| 写口播、做简报或使用模型分析 | 本机 DeepSeek 配置和对应 Bot 标明的运行时。内置口播使用锁定的 DSH Web Host，内置素材简报使用 Hermes ACP。 |
| 运行自媒体工作台工具 | 安装 Self Media Workbench，并在本机依赖里登记工作台及其 Python。视频处理需 FFmpeg 和 FFprobe。转录和字幕相关 Bot 还需工作台可用的语音识别模型。 |
| 用英语教培 Bot | 从 Bot广场直接打开内置教培功能。首次准备源码安装的课件和练习生成环境时，运行 `npm run setup:teaching`。教培任务助手使用 Hyper Bot 的 DeepSeek 配置。 |
| 接续原教师业务数据 | 由维护者在个人工作区启用 `HYPER_BOT_TEACHING_ACCESS=teacher`，配置原工作台端口和证书后，使用原教师账号。独立部署可直接进入，各群有独立教培数据。 |

## 单 Bot 对话

1. 从左下角打开 **Bot广场**，先选 **自媒体** 或 **英语教培**，再用横向小类或搜索框缩小范围。例如，想把录音变成文字，就选 **自媒体 → 剪辑 → 语音转录**。
2. 读卡片上的用途、所需材料和交付物。点 **添加到工作区** 或 **打开对话**。已添加的 Bot 出现在侧栏 **Bot** 标签中，从那里可以继续原会话，也可新建一次独立任务。
3. 按对话里的提示提供材料和任务说明。文字材料可按入口粘贴或上传。需要引用原文的任务，请保留你希望 Bot 使用的具体句子。教培表单则按字段选教材、学员或课程。
4. 执行后点结果，在右栏预览或下载。口播稿在 **确认写入** 后才成为原工作台的正式分镜版本。想先改内容，可点 **先改这版**，补充修改意见后再提交审批。
5. 找旧对话时，在左侧 **搜索会话** 直接输入关键词并提交。结果页属于当前工作区，侧栏也会保留最近提交的搜索。

口播和简报对话中，Enter 或 Ctrl+Enter 发送，Shift+Enter 换行。新建口播会话时选 **载入书店演练**，可用两份示例材料试做一条 45 秒分镜。

## 群组里接力做一件事

以“给读书会视频挑剪辑点，再让第二个 Bot 核对数量”为例。

1. 点 **群组 → 新建群组**，命名为“读书会视频”，点「选择文件夹」，选择一个已存在的独立目录，并勾选 **音乐卡点** 和 **教培任务助手**。多个群组可以选择同一个 Bot。各群的对话、业务记录和文件分别保存。
2. 在群聊上传一段带音乐的音频。输入 `@`，从成员列表选择 **音乐卡点**，发送“标出适合换镜头的时间”。一条消息可派给一位成员，普通群消息也能留在聊天记录里。
3. 在回复中打开 **音乐卡点.csv**。右栏会列出候选时间和相对强度。再点 **选群文件**，勾选这个 CSV，发送“@教培任务助手 这个表里一共有几个时间点？”第二个 Bot 会收到这次选中的文件。
4. 结果写入 **所选文件夹 → 群组文档**。列表使用原文件名，磁盘文件带有独立编号。同名结果可分别回查。在窄屏上点 **群组文件** 即可看文件列表。需要复制完整路径时，再展开 **文件保存位置**。
5. 需要写入确认时点 **继续处理**。登记学员等操作可点 **在群内填写**，核对表单后保存。打开 **群组成员 → 从 Bot广场添加成员**，可让其他 Bot 加入已有群组。

群内教培任务助手可以读取每份不超过 16,000 字节的 TXT、Markdown、CSV 或 JSON。群内口播和简报接收 TXT 或 Markdown，每份不超过 64,000 字节。课件和练习每次附一份教材。想手选知识点和题型，请打开课后练习的单 Bot 会话。在群里直接派活会按已识别的前几个知识点生成两份练习。

## 自媒体的 22 个 Bot

做账号分析、对标或复盘时，把作品记录、统计数据和原句放进 **补充授权文字**，在任务说明里写想比较的问题。做发布复盘时附实际采集时刻和时区，例如“北京时间 11 月 24 日 20:00”，同时注明是发布后 24 小时还是 48 小时的数据。这样才能把结论对应到正确的时间范围。

### 文案

| Bot | 准备什么 | 第一次可以这样用 | 得到什么 |
|---|---|---|---|
| **自媒体口播** | 选题、目标观众、预估时长及可引用的文字材料 | “给第一次逛独立书店的人写一条 45 秒口播，用采访里的原话开场。”预览后确认写入。 | 带台词、画面建议、字幕和时间码的分镜稿 |
| **素材简报** | 2–6 份可引用的文字材料，可粘贴或上传 TXT、Markdown | “把两份访谈中一致和冲突的说法列出来，每条附原句。” | 附原文引用的简报，可导出 Markdown |
| **选题策划** | 账号方向、目标观众和手头的选题线索 | “针对刚开始准备口语考试的学生，从这份问答里挑三个能拍的选题。” | 备选题目、切入角度和选择理由 |
| **发布准备** | 目标平台、稿件、素材使用权限说明 | “为这篇书评准备发布文案，单列发出前还要确认的素材授权。” | 发布文案和发布前核对清单 |

### 账号

| Bot | 准备什么 | 第一次可以这样用 | 得到什么 |
|---|---|---|---|
| **账号分析** | 账号面向谁、代表作品和同一时段的数据 | “这几条视频播放接近，为什么收藏差很多？先给我一个能验证的改动。” | 账号诊断、判断依据和调整建议 |
| **对标拆解** | 对标账号与你自己的作品样本、观察或数据 | “比较两组同主题视频的前十秒，挑一个我们下次可以试的开头。” | 差异对照和可尝试的做法 |

### 拍摄与制作

| Bot | 准备什么 | 第一次可以这样用 | 得到什么 |
|---|---|---|---|
| **制作流程** | 想做的视频和已经准备好的材料 | “已经有采访录音和三段空镜，还没写稿，下一步先做什么？” | 制作步骤和建议的起点 |
| **镜头库与解释图解** | 要解释的文字、步骤或关系，参考图可选 | “把借书、登记、归还这三个步骤画成一个镜头。” | 可下载、可用于剪辑的图解镜头（MP4） |
| **布光与灯位** | 场地照片、实际空间和手头灯具的说明 | “人物靠窗，右侧有一盏 LED。附上场地照片，请给我三种试摆方法。” | 三档布光建议和试拍方案 |

### 剪辑

| Bot | 准备什么 | 第一次可以这样用 | 得到什么 |
|---|---|---|---|
| **自动剪辑** | 按播放顺序排列的视频、每段时长和画幅 | 依次上传三段视频，每段取开头两秒，导出竖屏粗剪。 | 粗剪视频（MP4）和镜头时间轴 |
| **多素材时间轴** | 按顺序排列的视频或图片、每段时长 | 按“门头照片 → 店内视频 → 书封照片”的顺序上传，导出一版预览。 | 混排成片（MP4）和镜头时间轴 |
| **语音转录** | 一段声音清楚的录音或视频，需本机语音模型 | 上传采访录音，运行后先在逐字稿中找出嘉宾的原句。 | 可在对话中查看的逐字稿 |
| **字幕与口播剪辑** | 有清晰人声的口播视频，需本机语音模型 | 上传带人声的视频，导出 MP4 和 SRT，校对字幕中的人名。 | 剪辑后的视频（MP4）和字幕（SRT） |
| **配图、重点字幕与画面提示** | 口播视频、要强调的内容及位置，配图可选，需本机语音模型 | “说到借阅规则时突出关键词；讲到入口时用我附的门口照片。” | 带画面提示的视频（MP4）和字幕（SRT） |
| **行业模板剪辑** | 口播视频、所属行业和剪辑要求，需本机语音模型 | “用适合门店探访的模板剪这条口播，保留招牌和地址。” | 按模板剪辑的视频（MP4）和字幕（SRT） |
| **自定义剪辑方案** | 视频类型、观看目的和你想保留的剪辑习惯 | “给每周书评做一个固定剪法，先提问题，再引原文，最后留一个讨论题。” | 经过工作台校验的剪辑方案 |
| **高级口播** | 已有口播视频、补充镜头和各镜头用途 | “人物正面镜头做主线，讲到装帧时切到书脊特写。” | 口播成片（MP4）和镜头时间轴 |
| **镜头转场** | 至少两段按顺序排列的视频或图片 | 依次放入日景和夜景两段素材，预览它们之间的淡化过渡。 | 带淡化转场的成片（MP4） |
| **蒙版与遮罩** | 两份视频或图片，先放底图，再放叠加素材 | 先上传主讲视频，再传一张书封，把书封作为右上角的小窗。 | 带固定位置画中画的成片（MP4） |
| **音乐卡点** | 一段音乐，或带音乐的视频 | “标出这段音乐里适合切镜头的位置。”打开 CSV，按时间试听。 | 候选剪辑点的时间、强度和可下载的 CSV 表 |
| **画面特效与动效** | 视频或图片、要加效果的位置和预期动作 | “开场两秒缓慢推近到封面中央的书名。” | 带动效的成片（MP4）和镜头时间轴 |

| 某次口播或简报的历史版本 | 完成后在 **版本** 页选旧稿，可查看引用、导出 Markdown 或含引用清单的 ZIP。用 **继续改稿** 可以接着改。 | 会话右栏和左下角 **⋯ → 成果库**。独立口播工作台的项目可以在个人工作区新建会话时连接。 |

## 版本、维护与恢复

- **改稿与授权**。可以在新任务中沿用仍获授权的原文，或点 **另起任务** 从空白开始。材料页的 **管理授权** 可设置到期或撤回。执行撤回前读清界面列明的受影响材料与稿件。
- **运行回执**。在 **⋯ → 维护中心 → 运行回执** 查看运行结果、模型用量、失败与重试，也可登记实际账单和人工工时，导出当前周期记录。
- **停止与断线**。需要终止时点 **停止任务**。遇到“停止未确认”或关机时正处于写入阶段，先从 **⋯ → 断线核对** 查询原任务是否已经保存，再决定是否重试。
- **装配自己的 Bot**。在 **维护中心 → Skill 与 Harness** 导入有权使用的 Skill，核对来源，再到 **装配 Bot** 选择运行时、规则顺序和验证样例。保存候选后验证样例，从版本卡查看成果再启用。旧会话保留已绑定的版次，需要时可选择 **切换版本续接**。
- **备份与恢复**。退出托盘应用后，使用工作区维护命令创建备份、核对清单，再恢复到新的空目录。恢复群组后重新选择群文件夹，工作区会从备份重建文件副本。DeepSeek 凭据需在恢复后的工作区单独配置。具体命令见 [Windows 测试包使用说明](Windows%20测试包使用.md)。

默认应用数据在 `%LOCALAPPDATA%\HyperBot`，指定 `HYPER_BOT_DATA_DIR` 可使用其他目录。备份目标和恢复目标请分别选新的目录。以下命令中的尖括号连同内容一起换成实际的路径。

```text
npm run workspace -- backup "<当前工作区>" "<新备份目录>"
npm run workspace -- verify "<备份目录>"
npm run workspace -- restore "<备份目录>" "<新工作区>"
```

### 遇到这些情况

| 现象 | 操作 |
|---|---|
| 卡片写着“依赖待配置”或“需语音模型” | 从卡片查看缺项，在本机依赖中登记运行时，或在原自媒体工作台准备语音模型，再回到原会话重新检查。 |
| 提示当前工作区有任务正在执行 | 等本轮任务或维护结束后再发送下一项，可在原会话查看执行状态。 |
| 两个群无法绑定同一文件夹 | 分别建立文件夹，例如“读书会”和“夏令营”作为同一级的两个目录，分别绑定。 |
| 想让另一个 Bot 看上一份结果 | 在同一个群点 **选群文件**，勾选结果再派活。需要长期复用的文字约定，可另存工作区记忆。 |
| 想把教师答案发给学生 | 在练习预览切到 **学生练习单** 后下载，教师参考版单独保存。 |
| 在群组菜单里找不到个人档案 | 切回个人工作区，从左下角 **⋯ → 档案** 打开。 |
