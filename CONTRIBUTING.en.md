# Contributing

[简体中文](CONTRIBUTING.md) · [Project README](README.en.md) · [License scope](LICENSE-NOTE.en.md)

Include the app version, Windows version, reproduction steps, and expected behavior in GitHub issues. Use synthetic materials and remove credentials, conversations, databases, and local paths from reports.

Run `npm run build` and `npm run check` before submitting a change. Describe the paths you verified. For model or runtime changes, record whether you used a fixture or the actual component.
