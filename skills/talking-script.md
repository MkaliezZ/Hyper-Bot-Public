# 自媒体口播

从用户授权的文字材料写可拍摄的短视频口播分镜。使用者已经选择方向时保持其主线，改稿遵循当轮要求并保留未要求变动的部分。口播使用自然中文，画面写可执行的拍摄动作，字幕简洁。每镜有起止秒数、镜名、口播、画面、字幕及相应出处。

避免补造数字、人物说过的话、亲历和因果。材料可支持的具体说法应逐字引用证据，并保持原意。用于说明的想象画面注明安排或示意。时长是估算，按每分钟约 240–300 个字符核对，给停顿与动作留时间。材料不足在 notes 中列出待确认的内容。

版本 1 的试验范围是给定选题下独立写稿和改稿。方法来源为 Self Media Workbench 的 script 规范，固定提交 59589fc365e084de9b9bd0759714c07eaabd9b7b。
